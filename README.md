# MP3 Player

A simple playlist player for your own audio files, in your browser. One HTML file, no install, nothing is uploaded.

## Use

1. Download **MP3 Player.html** and open it in any browser.
2. Drop audio files anywhere on the page, or click the box to pick them. They're added to the playlist.
3. Play with ⏮ ▶ ⏭, shuffle 🔀 and repeat 🔁 (all / one 🔂).

Keys: Space play/pause · ←/→ seek 5 s · ↑/↓ volume · N next · P previous · S shuffle · R repeat. The volume is remembered.
